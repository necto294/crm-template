# crm-template

Шаблон web‑CRM (B2B) для заказной разработки: self‑hosted на сервере заказчика в РФ, одна установка = одна организация.

## С чего начать
1. Прочитай `AGENTS.md` и `docs/spec/00-decisions.md`.
2. Выбери библиотеку входа и запиши решение в `docs/adr/0001-auth-library.md`.
3. Выполняй задачи из `docs/spec/tasks.md` по порядку, по одной.

## Состав
- `AGENTS.md` — правила для ИИ‑агента.
- `docs/spec/` — спецификация (требования, архитектура, роли, безопасность, тесты, передача).
- `docs/adr/` — записи архитектурных решений.
- Код (`apps/`, `packages/`, `infra/`, `tests/`) создаётся задачами из `docs/spec/tasks.md`; структура описана в `docs/spec/architecture.md`.

Лицензионных проверок в коде нет. Объёмы из `docs/spec/capacity.md` — ориентиры для проектирования.
