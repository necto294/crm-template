# Правила внесения изменений

- Одна задача — один pull request.
- Перед отправкой: `pnpm lint && pnpm typecheck && pnpm test`.
- Каждое изменение — с тестами: положительный и отрицательный сценарий.
- Не добавляй зависимости и внешние сервисы без обоснования (см. `AGENTS.md`, правило 10).
- Не коммить секреты, реальные данные заказчика и персональные данные.
- Изменения структуры и архитектурные решения — через запись в `docs/adr/`.
