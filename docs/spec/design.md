# Дизайн интерфейса

## Направление
Спокойное рабочее пространство: нейтральный серый фон, один акцентный цвет, тонкие границы, скругление 8–12 px, компактная плотность данных, светлая и тёмная темы.

## Каркас
Свёртываемая левая навигация (Dashboard, CRM, Задачи, Отчёты, Ассистент, Настройки). Верхняя панель: глобальный поиск (Ctrl+K), быстрое создание, уведомления, профиль. Правая панель деталей записи.

## Экраны
- Дашборд: 4–6 показателей, воронка, сделки по стадиям, задачи на сегодня.
- Списки: серверная пагинация, закреплённый заголовок, видимость колонок, сохранённые фильтры, панель массовых действий.
- Карточка: свойства, лента активностей, связанные записи.
- Kanban: сумма и количество по колонке; перетаскивание с откатом при ошибке; меню «переместить на стадию» как альтернатива.
- Импорт: загрузка, предпросмотр со статусами строк и выбором действия, итоговый отчёт.
- Слияние: две записи рядом, выбор значения для каждого различающегося поля, подтверждение с итогом.
- Отчёт «Продажи по менеджерам»: таблица и диаграмма, фильтры, суммы по валютам отдельно.
- Ассистент: чат рядом с контекстом; карточки вызовов инструментов; подтверждение записи отдельным экраном с различиями.
- Настройки: пользователи, pipeline, приватность, ИИ.

## Токены
- Шрифт Inter (кириллица), локально. Текст 14 px, метаданные 12 px, заголовки 20–28 px.
- Интервалы 4/8/12/16/24/32. Цвета только через семантические переменные (background, foreground, muted, border, primary, danger).
- Тень только у всплывающих элементов и при перетаскивании. Анимации 120–180 мс, учитывать `prefers-reduced-motion`.

## Состояния
Для каждого экрана: загрузка, пусто, ошибка, нет прав.

## Доступность
WCAG 2.2 AA: управление с клавиатуры, видимый фокус, подписи и ошибки у полей, контраст, `aria-live` для асинхронных сообщений.

## Форматы РФ
Дата ДД.ММ.ГГГГ, число 1 234,56, телефон +7, валюта ₽. Интерфейс русский, английский второй (i18n; строки не хардкодить).
