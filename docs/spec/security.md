# Безопасность

## Вход и сессии
- Пароли: argon2id, минимальная длина 12.
- Блокировка и задержка после серии неудачных входов.
- Cookie `HttpOnly`, `Secure`, `SameSite`; срок жизни сессии, возможность отзыва.
- Защита от CSRF для изменяющих запросов.
- Сброс пароля: одноразовая ссылка с коротким сроком, нужен SMTP.

## Авторизация
- Роли: `manager`, `head`, `admin`, `viewer`. Матрица прав и ключи прав — в `roles.md`.
- Проверка по праву (`ресурс.действие`), а не по названию роли. Реализация в `packages/dal/src/policies`.
- Проверка прав в DAL на каждой операции. Проверки в layout, middleware и на кнопках — только UX.
- Server Actions и Route Handlers: аутентификация и права проверяются внутри, вход валидируется Zod.
- Клиенту только DTO.
- Нельзя удалить или понизить последнего администратора.

## Защита приложения
- CSP, HSTS; секреты только на сервере; в `NEXT_PUBLIC_*` секретов нет.
- Ограничение частоты запросов: вход, приглашения, импорт, поиск, ИИ, публичные формы.
- Webhooks: подпись HMAC, окно времени, идемпотентность, защита от SSRF.
- Файлы: проверка типа и размера, закрытое хранилище, выдача по временным ссылкам.
- Секреты интеграций в БД шифруются (версионированный ключ).
- Кэш: не кэшировать страницы и запросы с персональными данными без ключа, включающего пользователя.

## Цепочка поставки
Сканирование зависимостей в CI, фиксация версий (lockfile), SBOM, проверка отсутствия внешних сетевых запросов (разрешённые хосты в списке).
