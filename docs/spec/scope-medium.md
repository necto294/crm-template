# Medium — второй заказ (после пилота Standard)

Отдельный заказ с отдельной приёмкой. Не начинать, пока Standard не принят. Функции подключаются флагами в `packages/config/src/features.ts`.

1. Лиды: источники, статусы, конвертация в контакт, компанию и сделку; web‑формы.
2. Несколько pipeline, товары и позиции в сделке, прогноз.
3. Настраиваемые роли и права; пользовательские поля (фиксированный набор типов); видимость по отделам.
4. Расширенный поиск дубликатов по всей базе: нечёткое сравнение названий и контактов, оценка похожести, очередь на проверку и массовое слияние. Точные совпадения при импорте и ручное слияние уже есть в Standard.
5. Расширенные отчёты и экспорт; конвертация валют по заданному курсу.
6. Автоматизации: триггер → условие → действие; журнал запусков.
7. Webhooks: исходящие с подписью и повторными попытками; входящие.
8. Почта IMAP/SMTP: привязка писем к карточкам.
9. ИИ с записью: создание задач и заметок, смена стадии — только после явного подтверждения пользователя; поиск по заметкам (RAG).
10. Расширенный журнал аудита и политика хранения.
