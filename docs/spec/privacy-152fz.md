# Персональные данные (152‑ФЗ)

Технические требования. Юридические обязанности оператора лежат на заказчике.

## Локализация
- Все компоненты (БД, очередь, файлы, почта, логи, бэкапы, ИИ) работают в российском окружении.
- Запрещены зарубежные облачные сервисы для данных: облачный Sentry, Resend, зарубежный S3, внешняя аналитика, CDN для шрифтов и скриптов.
- Шрифты, иконки, скрипты — внутри приложения.

## Функции в CRM
- В карточке контакта: основание обработки, дата и источник согласия, срок хранения (`privacy_records`).
- Выгрузка всех данных контакта в файл.
- Удаление по запросу: физическое удаление персональных полей и связей; в истории остаётся обезличенная запись.
- Мягкое удаление допустимо для обычных записей; есть команда окончательной очистки по сроку.
- Журнал доступа к персональным данным: кто и когда открыл карточку; срок хранения ограничен настройкой.

## Журнал аудита и логи
- В аудит попадают идентификаторы, действие, список изменённых полей, время, пользователь. Значения персональных данных не копируются.
- Логи не содержат персональных данных; email и телефоны маскируются (`packages/observability/src/mask.ts`).

## Бэкапы
Шифруются, хранятся в РФ.

## ИИ
- Перед отправкой во внешнюю модель убираются лишние персональные данные (`packages/ai/src/privacy/redact.ts`).
- Факт передачи данных ИИ‑провайдеру фиксируется в журнале.
- Провайдер выбирает администратор.
