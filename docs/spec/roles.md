# Роли и права

Четыре роли. Одна установка = одна организация, роли глобальные. Первый созданный пользователь получает роль `admin`.

| Код | Название | Назначение |
|---|---|---|
| `manager` | Менеджер | Работает со своими компаниями, контактами, сделками и задачами |
| `head` | Руководитель | Видит и ведёт всю команду, назначает ответственных, смотрит отчёты, настраивает воронку |
| `admin` | Администратор | Пользователи, настройки, ИИ, приватность |
| `viewer` | Наблюдатель | Только чтение |

## Принципы
- Права — набор действий вида `ресурс.действие`. Роль = набор прав. Проверка в коде идёт по праву, а не по названию роли (это нужно для настраиваемых ролей в Medium).
- Права проверяются в `packages/dal/src/policies` на каждой операции. Скрытие кнопок — только UX.
- «Свои» записи: те, где `owner_id` = текущий пользователь, либо он создатель задачи или заметки.
- Роль меняет только `admin`. Нельзя снять роль `admin` с последнего администратора и нельзя понизить себя, если ты последний администратор.

## Матрица прав

| Действие | manager | head | admin | viewer |
|---|---|---|---|---|
| Просмотр своих записей (компании, контакты, сделки, задачи) | да | да | да | да |
| Просмотр чужих записей | настройка (по умолчанию нет) | да | да | да |
| Создание компаний, контактов, сделок, задач | да | да | да | нет |
| Изменение своих записей | да | да | да | нет |
| Изменение чужих записей | нет | да | да | нет |
| Назначение и смена ответственного | нет | да | да | нет |
| Перенос сделки по стадиям (своей) | да | да | да | нет |
| Мягкое удаление своих задач и заметок | да | да | да | нет |
| Мягкое удаление компаний, контактов, сделок | нет | да | да | нет |
| Слияние двух компаний или контактов | нет | да | да | нет |
| Окончательная очистка и удаление по запросу субъекта | нет | нет | да | нет |
| Дашборд по себе | да | да | да | да |
| Дашборд по всей команде | нет | да | да | да (чтение) |
| Отчёт «Продажи по менеджерам»: все строки | нет | да | да | да (чтение) |
| Отчёт «Продажи по менеджерам»: своя строка | да | да | да | да |
| Настройка воронки и стадий | нет | да | да | нет |
| Импорт CSV (включая выбор действий по дубликатам) | нет | да | да | нет |
| Экспорт CSV | свои записи | все записи | все записи | нет |
| Выгрузка данных контакта (152‑ФЗ) | нет | да | да | нет |
| Просмотр журнала действий | нет | да (без технических событий) | да | нет |
| Управление пользователями и ролями | нет | нет | да | нет |
| Настройки ИИ, приватность, интеграции | нет | нет | да | нет |
| ИИ‑помощник (чтение) | да, в пределах своих прав | да | да | да, в пределах своих прав |

Настройка `manager_sees_all_readonly` (в `settings`): если включена, менеджер видит чужие записи, но не меняет. По умолчанию выключена. ОТКРЫТО: уточнить у заказчика.

## Ключи прав
`company.read.own`, `company.read.all`, `company.create`, `company.update.own`, `company.update.all`, `company.delete`, `company.merge`; то же для `contact` (включая `contact.merge`), `deal` и `task` (без `merge`). Дополнительно: `deal.reassign`, `pipeline.manage`, `report.read.own`, `report.read.all`, `import.run`, `export.own`, `export.all`, `privacy.export`, `privacy.erase`, `audit.read`, `user.manage`, `ai.manage`, `ai.use`, `settings.manage`.

Реализация: `packages/dal/src/policies/permissions.ts` (список ключей), `role-permissions.ts` (набор прав каждой роли), `authorize.ts` (проверка, включая «свои» записи).

## Medium
Настраиваемые роли поверх тех же ключей прав; видимость по отделам. В Standard не реализуется.
