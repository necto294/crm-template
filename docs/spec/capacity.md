# Расчётные объёмы

Это ориентиры для проектирования индексов, пагинации и тестов. В коде они не ограничиваются: нет лицензионных проверок, режима «только чтение» по сроку и блокировок по числу пользователей или записей.

| Параметр | Standard | Medium |
|---|---|---|
| Пользователи | до 25 | до 100 |
| Записи (компании, контакты, сделки, задачи вместе) | до 50 000 | до 500 000 |
| Файлы | до 5 ГБ | до 50 ГБ |
| API‑запросов в минуту (защита от перегрузки, не коммерческий лимит) | 60 | 300 |

## Как использовать
- Индексы, пагинация и нагрузочные тесты рассчитываются на эти объёмы (см. `testing.md`).
- За пределами объёмов производительность не гарантируется; расширение — отдельная работа по согласованию с заказчиком.
- Ограничение частоты API (rate limit) остаётся как техническая защита (`security.md`).
- Ключ ИИ‑провайдера принадлежит заказчику, расходы на ИИ несёт он. В настройках ИИ есть месячный бюджет запросов, который задаёт администратор заказчика; при достижении ИИ отключается до следующего месяца, остальная CRM работает.
- Место на диске контролируется оповещением мониторинга (`deployment.md`), а не блокировкой в приложении.
