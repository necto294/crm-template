# Развёртывание, обновление, бэкапы

## Сервер для старта
4 vCPU, 8 ГБ RAM, 100 ГБ SSD, Ubuntu LTS, Docker. Для локальной модели ИИ — отдельный сервер с GPU.

## Установка (`infra/scripts/install.sh`)
1. Проверка Docker.
2. Создание `.env` с сгенерированными секретами.
3. Запуск Compose.
4. Создание первого пользователя `admin`.
5. TLS через reverse proxy (Let's Encrypt при наличии интернета или сертификат заказчика).

## Обновление (`update.sh`)
Резервная копия → загрузка новых образов → `prisma migrate deploy` → проверка здоровья → при ошибке откат образов (данные — из копии).

## Бэкапы
`backup.sh` по расписанию, шифрование, хранение на отдельном хранилище в РФ, срок хранения настраивается. `restore.sh` проверяется на тестовом стенде перед передачей и раз в квартал.

## Мониторинг
`/api/health`, `/api/ready`; структурные логи; оповещения о месте на диске, сбое очереди, сбое бэкапа.

## Режим без интернета
Образы поставляются архивом; при запуске нет внешних запросов; ИИ‑облако и внешняя почта отключены, если недоступны; шрифты и иконки внутри приложения.

## Документы поставки
Руководство администратора, руководство пользователя, инструкция по восстановлению, описание функций 152‑ФЗ, политика поддержки. Состав передачи и проверки — `handover.md`.
