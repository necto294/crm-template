# Безопасность

- Об уязвимостях сообщай владельцу репозитория напрямую, не в публичных задачах.
- Требования: `docs/spec/security.md`, `docs/spec/privacy-152fz.md`.
- Секреты хранятся только в переменных окружения и хранилище заказчика; в истории репозитория их быть не должно.
- Обновления безопасности выпускаются по условиям договора сопровождения.
